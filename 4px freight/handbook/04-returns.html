Returns

Y2KASEshop · Hinfung Eco-Tech Group Limited · United States

In short. Today, buyer returns go to TikTok in Commerce, California. TikTok destroys them. They do not come back to 4PX.

What this shop uses now

The return warehouse is US Platform Return Warehouse-West, 6557 Flotilla St. Dock#4, Commerce, CA 90040. TikTok said it may still send a return to whichever of its docks is closest to the buyer. The East dock you did not select is in Linden, New Jersey.

The checkbox you accepted says a correct return that TikTok receives is destroyed. You cannot ask for it back.

If you later want the goods back at 4PX

4PX’s West return building is USLAXB, West Los Angeles 2 (美西洛杉矶2仓). It is not Milliken Avenue, and it is not the shipping building. 4PX has not given you that street yet. When they do, add it under Warehouse & shipping, Return warehouses.

Do not use Houston 1 (美国休斯顿1仓, USHOUA) as a return address. The price card marks consumer returns there as no service (无服务). A return sent there is destroyed and billed as disposal.

If a return does reach 4PX

  • 4PX keeps it for 60 days from the day it is put away.
  • After 60 days with no instruction, 4PX can destroy it.
  • Destruction is billed as an outbound fee plus a disposal fee.
  • A return with no forecast and no customer code on the label is destroyed, with no later trace.

Warehouse service price card, sheet 退件服务价卡. Row 6 names the return warehouses. Row 8 is Houston, no service. Row 28 is the destruction rule. Row 30 is the 60-day limit.
